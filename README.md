# Rewind! 🎧

A retro-inspired music player built with HTML, CSS, and JavaScript.

Rewind! is a personal web development project that combines music playback with a nostalgic, playful interface. The goal was to create a music player that feels more personal and interactive than a standard streaming layout.

## Live Website

[View Rewind!](https://urbruhisha.github.io/rewind/)

## About the Project

I designed and developed Rewind! as a front-end project focused on interactive UI design and JavaScript functionality.

Users can browse songs, control music playback, create playlists, save favorites, and upload their own music through the interface.

The project also explores how visual design and functionality can work together to make a familiar experience — listening to music — feel more unique and personal.

## Built With

- HTML
- CSS
- JavaScript

## Features

- Music playback controls
- Play, pause, next, and previous tracks
- Song progress controls
- Playlists
- Favorite songs
- Custom song uploads
- Album artwork and song information
- Interactive UI elements
- Responsive layout
- Retro-inspired visual design

## What I Practiced

Rewind! helped me improve my JavaScript skills by working with audio playback, user interaction, dynamic content, and managing different music states.

It also gave me more experience designing an interface where functionality and visual design are equally important.
